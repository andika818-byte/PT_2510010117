Latihan ini bertujuan untuk memahami dasar-dasar kompilasi program C++, mengenali pesan kesalahan dari compiler, serta memahami fungsi warning pada proses kompilasi.
Pada file `rerata.cpp`, program awal menghitung rata-rata lima nilai menggunakan pembagi `3.0`.

Perbaikan dilakukan dengan mengubah pembagi menjadi `5.0`.

cpp
double rerata = (tugas + uts + uas + kehadiran + praktikum) / 3.0;
