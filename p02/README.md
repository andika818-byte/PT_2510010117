# Deklarasi Penggunaan AI
Alasan menggunakan AI sebagai alat bantu ialah:
AI dapat membantu memahami materi atau menjelaskan bagian-bagian kode
yang belum saya pahami serta membantu memeriksa kode yang eror.

Saya tetap mengerjakan dan menjalankan program sendiri di VS Code.
Hasil bantuan AI saya periksa kembali dengan menjalankan program dan
membandingkannya dengan ketentuan pada modul.
