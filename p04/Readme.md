# 1. Flowchart Huruf Mutu
Percabangan if-else bertingkat digunakan untuk menentukan huruf mutu berdasarkan nilai akhir. Kondisi diperiksa secara berurutan dari nilai tertinggi hingga ditemukan kondisi yang benar.
# 2. Bilangan Terbesar
Percabangan if-else dan operator logika && dapat digunakan untuk membandingkan tiga bilangan dan menentukan bilangan yang memiliki nilai terbesar.
# 3. Tahun Kabisat
Operator modulus % digunakan untuk memeriksa apakah suatu tahun habis dibagi 4, 100, atau 400. Operator logika && dan || digunakan untuk menentukan apakah tahun tersebut termasuk tahun kabisat.
# 4. Switch Menu
Tipe data char digunakan untuk menyimpan pilihan menu berupa karakter. Setiap case ditulis menggunakan tanda petik satu, seperti '1', '2', dan '3'. Pilihan 'k' ditambahkan untuk keluar dari program.
# 5. Percabangan Switch
Percabangan switch menggunakan ekspresi static_cast<int>(nilai) / 10 untuk menentukan huruf mutu berdasarkan kelompok nilai. Pada nilai 79.9, hasilnya sama dengan program if-else, yaitu huruf mutu B, karena nilai tersebut dikonversi menjadi 79 lalu dibagi 10 sehingga menghasilkan 7.
